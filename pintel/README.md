# Pintel — ядро чтения iPhone, сервер, касса и киоск

- `pintel_core` — чтение телефона по кабелю и отчёт (на нём всё остальное);
- `pintel-doctor` — консольный «врач»: полный сырой слепок, отчёт, качество чтения;
- `pintel_server` — один сервер и база на все точки: учётные записи и роли,
  журнал входов и действий, оценки с полным слепком, прайс, кэш Sickw,
  касса сотрудника в браузере, API киоска (`deploy/README.md` — как поднять);
- `pintel_kiosk` — клиентский киоск на Windows: подключил телефон → проверка →
  цена → талон (`kiosk.toml` рядом с exe: адрес сервера и токен киоска).

## Что это даёт

- **Чтение на pymobiledevice3** — стандарт индустрии, чистый Python. Нужен
  только iTunes (служба Apple Mobile Device). Никаких MSYS2 и bin-папок.
- **Устойчивость к «первому разу»**: ожидание готовности после «Доверять»,
  повторы с паузами, двойное чтение диска с пометкой «первое чтение устарело».
- **Имена узлов не угадываются** — берутся с карты IORegistry самого телефона.
- **Слепок целиком** сохраняется в JSON: любой сбой на новой модели правится
  по файлу, а не по догадке. С версии 3 в слепке лежат планы IOService и
  IODeviceTree полностью (все серийники модулей любой модели), узлы Wi-Fi,
  Touch ID и порта, ответ MobileGestalt (до iOS 17.4) и проба джейлбрейка
  через AFC — тот же набор источников, что у 3uTools (сверено по его модулю
  чтения idm_info.dll).

## Как пользоваться на Windows

1. Поставьте iTunes с сайта Apple (не из Microsoft Store).
2. Распакуйте `pintel-doctor` из Releases; `gservice.json` положите рядом
   с `pintel-doctor.exe`.
3. **Двойной щелчок по `pintel-doctor.exe`** — откроется меню. При первом
   запуске программа спросит ключ Sickw и сама создаст `config.toml`.
4. Пункт **2** — проверка окружения (драйвер, ключи, кабель).
5. Подключите iPhone, разблокируйте, нажмите «Доверять», пункт **1** —
   полная проверка: слепок, отчёт, история обслуживания Apple (попросит
   зайти в раздел на телефоне), Sickw. По окончании откроется папка `out\`.
6. Пришлите папку `out\<дата>_<серийник>\` разработчику: `snapshot.json`
   и `report.txt`. Если что-то упало — ещё `doctor_errors.log`.

Из командной строки то же самое: `pintel-doctor snapshot --apple 120 --sickw`,
`selfcheck`, `report файл.json`, `apple`, `sickw IMEI|balance`, `price`, `fixtures`.

## Sickw: какие услуги и как проверить

В `config.toml` в разделе `[sickw]` перечислены номера услуг, которые
дёргаются по IMEI: `services = [61]` (61 — iPhone CARRIER & FMI & BLACKLIST).
Номер любой услуги виден в кабинете Sickw: Services → в адресе `...&service=N`.
Можно указать несколько — ответы складываются в один паспорт, при расхождении
побеждает тревожный статус (BLACKLISTED, FMI ON). Каждая услуга — отдельный
кредит; ошибки Sickw не кэшируются, успешные ответы кэшируются по IMEI+услуга
вместе с сырым текстом, поэтому повторная проверка того же телефона бесплатна.

Проверить услугу глазами: `pintel-doctor sickw 35xxxxxxxxxxxxx --service 61 --fresh`
— программа печатает сырой ответ построчно и свой разбор. Если в разборе
стоит `null` там, где в сыром ответе значение есть, пришлите этот вывод
разработчику: разбор правится по кэшу без новых запросов.

## Как открыть кассу

Касса — это сайт, который отдаёт сервер Pintel. Два способа запустить сервер:

1. **Одним файлом на обычном компьютере** (попробовать, одна точка):
   распаковать `pintel-server` из Releases, рядом положить `gservice.json` и
   `server.toml` (по образцу `server.example.toml`), двойной щелчок по
   `pintel-server.exe` → пункт 2 «Создать администратора» → пункт 1
   «Запустить кассу». Откроется браузер с `http://127.0.0.1:8000`; с других
   компьютеров и телефонов сети — `http://<IP этого компьютера>:8000`
   (Windows при первом запуске спросит разрешение брандмауэра — разрешить).
   Окно сервера не закрывать. База — файл `pintel.db` рядом.
2. **На VPS для всех точек** — `deploy/README.md` (docker compose,
   PostgreSQL, ночные копии, HTTPS).

Разработка: `pip install -e ".[server,test]"`, `python -m pintel_server.cli
create-admin --login admin --name "Руслан"`, `python -m pintel_server.launcher run`.
На VPS — `deploy/README.md` (docker compose: PostgreSQL, приложение, ночные
копии, HTTPS). Роли: кассир (очередь, оформление по прайсу и ниже), старший
(любая цена, настройки), администратор (сотрудники, киоски, точки).
Аутентификация собрана в `pintel_server/auth.py` — тип входа меняется там.

## Киоск

`pintel-kiosk` из Releases, рядом `kiosk.toml` (см. `kiosk.example.toml`):
адрес сервера и токен из «Настройки → Киоски». Без связи киоск работает
автономно по последнему прайсу и досылает оценки, когда связь появится.
Esc — выйти из полного экрана, Ctrl+Q — закрыть. Слепки и журнал:
`%LOCALAPPDATA%\PintelKiosk`.
