# Какие данные о телефоне мы получаем и откуда

Разбивка по источникам. Главное правило: **по кабелю данные телефона — первоисточник**
(их нельзя подделать со стороны аппарата), Sickw — внешняя сверка по IMEI, прайс — из
Google Таблицы.

Обозначения источников:
- 🔌 **Кабель, сразу** — читается по USB без интернета и без действий клиента, на всех iOS.
- 🔐 **Кабель, MobileGestalt** — тоже по кабелю, но через отдельный канал: до iOS 17.4
  напрямую, на iOS 17.4+ через туннель CoreDevice (как 3uTools). Не поднялся туннель —
  не критично, вердикт по деталям даёт основной канал.
- 👆 **Кабель + клиент** — по кабелю, но нужно, чтобы клиент открыл раздел на телефоне.
  Только даты ремонтов, необязательно.
- 🌐 **Sickw** — по IMEI через интернет, платный запрос. Независимо от телефона.
- 📊 **Прайс** — из вашей Google Таблицы.
- 🧮 **Считаем сами** — выводим из данных выше.

## 5. Подлинность деталей — 🔌 кабель + 🔐 MobileGestalt

Привязка каждого модуля к плате. Это те же данные, по которым Apple показывает «Unknown Part».

| Сигнал | Источник | Что проверяет |
|---|---|---|
| Face ID ↔ плата | 🔌 | криптопривязка ИК-камеры к чипу |
| Taptic ↔ плата | 🔌 | вибромотор прошит под эту плату |
| Экран: калибровка | 🔌 | калибровка панели совпадает с ожидаемой |
| Экран: стекло ↔ панель | 🔌 | серийник стекла входит в серийник панели |
| Датчик приближения | 🔌 | серийник совпадает с записанным в плате |
| Тачскрин | 🔌 | критических ошибок нет |
| Камеры (основная/широкая/теле) | 🔌 | модули называют серийники |
| печать_цела (FDRSealingStatus) | 🔐 | цела ли заводская печать |
| сервисная_деталь (IsServicePart) | 🔐 | ставили ли сервисную деталь |
| аутентификация_батареи | 🔐 | оригинальность батареи по Apple |
| **детали_вердикт** | 🧮 | итог: родные / меняли / замена — **всегда есть ответ** |

## 6. Серийники деталей с датами — 🔌 кабель, сразу

Для каждой: серийник, дата выпуска (из серийника), производитель/фабрика где знаем.
Материнская плата, аккумулятор, основная/сверхширокая/фронтальная камеры, ИК-камера
Face ID, экран (панель), экран (стекло), Taptic Engine, датчик приближения.

## 7. История обслуживания Apple — 👆 кабель + клиент (необязательно)

Только **даты ремонтов и метка «б/у»**. Вердикт по деталям уже есть из п.5 без этого.
Детали: аккумулятор, экран, камера, Face ID, верхний модуль, плата, заднее стекло,
корпус. Есть на iPhone XR/XS/SE2/SE3 (часть), iPhone 11 (часть), iPhone 12+ (полностью),
iOS 15.2 и новее. У iPhone X и старше раздела нет.

## 8. Прочее по кабелю — 🔌

- Джейлбрейк: следы через AFC (пути Cydia/Sileo и т.п.).
- NANDInfo: разбор служебного блока накопителя, сверка прошивки.
- Цвет корпуса: 🔐 через MobileGestalt (на iOS 17.4+ — через туннель).

## 9. Sickw — 🌐 по IMEI, интернет, платно

Независимая сверка по базам Apple GSX. Ключ только на сервере, кэш общий на все точки.

| Поле | Что это |
|---|---|
| чёрный_список, в_чёрном_списке | заявлен ли утерянным/краденым |
| icloud, fmi_включён | «Найти iPhone» по базе |
| оператор, sim_lock | привязка к оператору |
| гарантия, гарантия_до | статус и дата гарантии |
| дата_покупки, страна_покупки | когда и где куплен |
| подменный (Loaner) | аппарат Apple по подмене |
| демо (Demo Unit) | витринный образец |
| восстановленный (Refurbished) | заводской реф |
| замена_по_гарантии (Replaced) | выдан Apple по замене |
| регистрация | статус регистрации |
| цвет, объём, модель | заводская конфигурация (сверка с кабелем) |

Служба 61 даёт перечисленное. Чёрный список и FMI зависят от выбранной службы Sickw.

## 10. Цена и вердикт — 📊 + 🧮

- Цена: по вашей сетке износа из Google Таблицы (столбец по здоровью батареи).
- Итог: ИДЕАЛ / ХОРОШИЙ / ПРОВЕРКА НЕПОЛНАЯ / ПРОБЛЕМНЫЙ.
- Списки для сотрудника: СТОП (не брать), СДЕЛАТЬ, ВНИМАНИЕ, НЕ ПРОЧИТАЛОСЬ.
- Качество чтения: повторы, тайминги, какой канал MobileGestalt сработал.

## Что чем проверяется дважды (перекрёстная сверка)

| Параметр | Кабель | Sickw |
|---|---|---|
| «Найти iPhone» | 🔌 два канала телефона | 🌐 база Apple |
| Цвет / объём / модель | 🔌 / 🔐 | 🌐 заводская конфигурация |
| Чёрный список | — | 🌐 только Sickw |
| Подлинность деталей | 🔌 + 🔐 | — только кабель |
| Гарантия, дата покупки | — | 🌐 только Sickw |

Расхождение кабеля и Sickw (например «Найти iPhone») мы показываем сотруднику отдельно.
