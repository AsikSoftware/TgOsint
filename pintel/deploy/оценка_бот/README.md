# Медиа сделки через бота Оценки

Приложение на точке не хранит фото и видео у себя и не поднимает свой бот: сотрудник
открывает ссылку на **бота Оценки**, шлёт туда видео и фото, бот складывает их `file_id`
в таблицу обмена, приложение их забирает и создаёт сделку. Хранение бесплатное — так же,
как Оценка хранит медиа обычных сделок.

Заодно решается вопрос «кто проводил оценку»: бот узнаёт сотрудника по `chat_id`, и он
становится `user_grade` сделки. Отдельно выбирать оценщика в программе не нужно.

## Что поставить (два шага)

1. **Таблица обмена** — один раз, сначала в тестовой базе:

       psql -U postgres -d pintel_ocenka_test -f kiosk_media.sql

2. **Обработчик бота** — положить `kiosk_media.py` в `handlers/` и включить его в
   `main.py` **до** `router_start`:

   ```python
   from handlers.kiosk_media import router_kiosk_media
   ...
   dp.include_router(router_kiosk_media)   # ПЕРЕД dp.include_router(router_start)
   dp.include_router(router_start)
   ```

   Порядок важен: `router_start` ловит любой `/start` и заберёт нашу ссылку себе.
   Ничего другого в боте менять не нужно — свои `/start` он обрабатывает как раньше,
   наш обработчик срабатывает только на ссылку вида `/start p<КОД>`.

## Как это выглядит у сотрудника

1. В программе на точке — QR и ссылка с кодом.
2. Открыл телефоном → бот: «Принимаю медиа для сделки, Асылбек».
3. Прислал видео и фото → «Готово».
4. В программе медиа появились, видно, кто их прислал; дальше «Отправить в Оценку».

## Почему видео обязательно

Карточку сделки Оценка открывает так:

```python
media = [InputMediaVideo(media=device.video_phone)]
```

Поля `video_phone` она не проверяет: сделка без видео не открывается по кнопке вовсе.
Поэтому и бот, и программа не дают закончить без видео.

## Что приложению нужно в kiosk.toml

```toml
ocenka_db_url   = "postgresql+psycopg://…/pintel_ocenka_test"
ocenka_bot      = "pintel_ocenka_bot"   # имя бота для ссылки (без @)
ocenka_shop_litera = "16/38"
```
