# Pintel Проверка — приёмка iPhone

Полноэкранный киоск на Qt Quick — экран видят клиенты. Логотип на весь
экран; телефон подключили — проверка запускается САМА: данные по кабелю,
Sickw сразу (кэш по IMEI бережёт деньги), вердикт Apple слушается
непрерывно, пока телефон на проводе. Дальше ручные проверки и финал.
Настройки — шестерёнка в углу стартового экрана. F11 — оконный режим.

## Готовая сборка — ничего собирать не нужно

GitHub собирает программу сам, на настоящей Windows-машине, при каждом
изменении кода: ставит libimobiledevice из подписанных пакетов MSYS2,
собирает exe, **запускает его и проверяет по HTTP**, что интерфейс отвечает
и все инструменты на месте, — и только после этого выкладывает zip.

Скачать: страница **Releases** репозитория → свежая «PintelCheck для
Windows» → `PintelCheck_Windows_x64.zip`. Распаковать, поставить iTunes
(ради драйвера Apple, один раз), запустить `PintelCheck.exe`. Всё.

Разделы ниже — про ручную сборку, если понадобится собрать без GitHub.

## Запуск из исходников

```
pip install pyside6 google-auth requests
python3 app.py
```

Откроется киоск на весь экран. Логика — стандартная библиотека;
Qt — интерфейс, google-auth+requests — прайс из закрытой таблицы.

## Прайс из закрытой Google Таблицы (сервис-аккаунт)

1. В Google Cloud Console создайте сервис-аккаунт, включите Sheets API,
   скачайте его ключ JSON и положите рядом с программой как `gservice.json`.
2. В таблице нажмите «Настройки доступа» и добавьте email сервис-аккаунта
   как Читателя. Таблица остаётся закрытой для всех остальных.
3. В программе: ⚙ Настройки → «Обновить прайс из таблицы».

Без gservice.json работает запасной путь — таблица, открытая по ссылке.

## Сборка exe — на Windows, двойным щелчком

Запусти **`BUILD.bat`**. Он поставит PyInstaller, проверит наличие
libimobiledevice и соберёт программу в `dist\PintelCheck\`.

**На точку копируй всю папку `PintelCheck` целиком**, а не один файл:
рядом с exe лежат ресурсы, прайс и база приёмок.

Кросс-сборки не существует: `.exe` собирается только на Windows, с macOS
это сделать нельзя. Файл сборки `PintelCheck.spec` общий для обеих систем
и на macOS проверен — собранная программа запускается, отдаёт интерфейс,
выкладывает прайс наружу и сохраняет базу между перезапусками.

Сборка идёт **в папку, а не в один файл**, намеренно: однофайловая версия
распаковывает ~10 МБ при каждом запуске, это 15 секунд молчания до старта.
На точке продавец за это время решит, что программа сломалась.

### Папка bin — программы для чтения телефона

Официальных сборок libimobiledevice под Windows не существует, только
сторонние. Класть на кассовый компьютер исполняемые файлы неизвестного
происхождения не стоит, поэтому источник выбираете вы:

1. Поставь **MSYS2** с https://www.msys2.org/ (проект с подписанными пакетами)
2. Открой «MSYS2 UCRT64» и выполни:
   `pacman -S mingw-w64-ucrt-x86_64-libimobiledevice`
3. Запусти **`GETBIN.bat`** — он разложит нужные файлы в `bin/`

Зависимости определяются чтением таблицы импорта самих программ, а не
угаданным списком: угаданный рано или поздно окажется неполным, и программа
упадёт на точке с невнятной ошибкой.

На самой машине дополнительно нужен **Apple Mobile Device Support** — он
ставится вместе с iTunes и даёт драйвер USB.

## Настройка на точке — одна кнопка

Продавцу не нужно ничего понимать про драйверы. Варианта два:

- в самой программе: **«Настройка компьютера»** на первом экране — покажет,
  что готово, чего не хватает и что нажать;
- до первого запуска: файл **`SETUP.bat`** — то же самое, но из проводника.

Программа **ничего не скачивает из интернета сама** — это защита кассового
компьютера. libimobiledevice едет в комплекте, в папке `bin/`. Единственное,
что ставится руками, — драйвер Apple: он идёт вместе с iTunes, и скрипт
открывает нужную страницу Apple сам.

## Что делает каждый этап

**Этап 1 — кабель.** Паспорт, износ батареи, вердикты по деталям, юридический
статус. Плюс два внешних источника по кнопке:

- **Вердикт Apple** — тот самый экран «Запчасти и история обслуживания».
  По USB он не отдаётся, но его считает демон `mobilerepaird` и пишет
  результат в системный журнал, а журнал по кабелю читается. Нужен один шаг
  руками: зайти в раздел на телефоне. Именно **переход внутрь** — на уже
  открытом экране Настройки отдают кэш.
- **Sickw** — чёрный список, цвет, заводская конфигурация, даты покупки
  и активации. Независимо от телефона, то есть подделке со стороны аппарата
  неподвластно. Запрос платный, поэтому по кнопке и с кэшем по IMEI.
  Ключ кладётся в `~/.sickw_key`, в приложение он не вписывается.

Предварительная цена считается сразу и пересчитывается, когда приходят
Apple и Sickw.

**Этап 2 — то, что по кабелю не проверить.** Кабель отвечает на «оригинал или
нет», но не на «работает или нет». Веб-тест в браузере телефона плюс отметки
приёмщика: косметика, динамик, кнопки, влага. Здесь же вписывается цвет —
по кабелю он не определяется.

**Этап 3 — финал.** Пока ручная фиксация итоговой цены и способа выкупа.
Связка с Pintel Оценка, Pay и МойСкладом — следующим шагом.

## Цены

`prices.json` — **цифры там заглушечные**. Прайс магазина я не выдумывал:
ошибка в базовой цене дороже любой ошибки в диагностике. Заполните базу по
модели и объёму и размеры вычетов. Пока база не заполнена, приложение честно
пишет, что цены нет, и показывает только вычеты.

## Где что лежит

```
app.py            точка входа
backend.py        мост ядро → интерфейс, автоматика киоска
qml/Main.qml      киоск-интерфейс (Qt Quick)
core/gsheet.py    прайс из Google Таблицы (Sheets API / CSV)
core/device.py    кабельный слой (libimobiledevice)
core/verdict.py   правила: сырьё -> вердикты по деталям
core/apple.py     вердикт Apple из системного журнала
core/sickw.py     внешняя база
core/price.py     предварительная оценка
core/store.py     база приёмок (SQLite)
core/server.py    старый локальный сервер (клиентом не используется)
web/              логотип и иконка; старый веб-интерфейс, не используется
data/checks.db    база приёмок (создаётся сама)
core/setup.py     проверка готовности рабочего места
prices.json       прайс — ЗАПОЛНИТЬ
BUILD.bat         сборка (запускать на Windows)
build.py          сама сборка, весь текст здесь
SETUP.bat         настройка на точке
setup_check.py    сама проверка, весь текст здесь
PintelCheck.spec  описание сборки
core/paths.py     где что лежит внутри собранной программы
```

В базу пишется **сырьё целиком**, а не только вердикты. Это нужно, чтобы
пересчитать уже принятые аппараты новыми правилами, не трогая телефоны.
