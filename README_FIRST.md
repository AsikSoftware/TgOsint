# Перенос на Windows

## Что в этом архиве

```
project/pintel_check/  приложение Pintel Проверка — главное
memory/                накопленные знания (копировать в Claude Code)
mac_scripts/           прежние bash-скрипты, работают только на macOS
data/                  журнал приёмок и описи собранных аппаратов
```

## Шаг 1. Поставить Claude Code на Windows

Проще всего — то же приложение, что на маке:

**x64:** https://claude.ai/api/desktop/win32/x64/setup/latest/redirect
**ARM64:** https://claude.ai/api/desktop/win32/arm64/setup/latest/redirect

Права администратора не нужны. Войти тем же аккаунтом, что на маке.

Если нужна командная строка, в PowerShell:
```powershell
irm https://claude.ai/install.ps1 | iex
```

Стоит поставить **Git for Windows** (git-scm.com/downloads/win) — без него
часть команд выполняется через PowerShell вместо привычного bash.

## Шаг 2. Разложить файлы

1. `project/pintel_check` — положить куда удобно, **путь только латиницей**.
   `D:\pintel_check` подойдёт, `D:\Рабочий стол\ББАРБАРОС` — нет: русские
   буквы в пути уже один раз ломали сборку.

2. `memory/*.md` — скопировать в
   `%USERPROFILE%\.claude\projects\<папка-проекта>\memory\`
   Папка проекта создастся сама при первом открытии проекта в Claude Code.
   Можно и позже: просто скажите «перенеси память из папки memory».

3. `data/` — положить рядом с проектом, если захотите продолжить
   накопление статистики.

## Шаг 3. Собрать программу

Внутри `pintel_check`:

1. `GETBIN.bat` — соберёт папку bin (сначала нужен MSYS2, скрипт объяснит)
2. `BUILD.bat` — соберёт программу
3. `SETUP.bat` — проверит готовность компьютера

## Чего НЕ переносится

**Сам разговор.** История сессий хранится на каждой машине отдельно,
облачной синхронизации нет. На Windows начнётся новый разговор.

Чтобы он не начался с нуля — память из папки `memory/` и есть
накопленный контекст. Плюс файл `STATE.md` рядом: в нём коротко,
где мы остановились.

## Почему всё названо латиницей

Русские имена файлов в zip-архиве, собранном на маке, при распаковке
Проводником Windows превращаются в «??????». На этом мы уже спотыкались,
поэтому имена здесь только английские. Текст внутри файлов — русский,
с ним проблем нет.
